# /lhg-xiaohongshu:xhs-title —— 标题专项

用户输入在 `$ARGUMENTS` 中：`<产品卖点/笔记主题> [--count 8]`。`--count` 控制候选标题数量（默认 8）。

小红书的标题决定 80% 的点击率。本命令只做标题，不写正文。

## 流程

### 1. 批量生成（lhg-xhs-copy 第 3 节公式库）
用 8 大标题公式各生成 1 个候选（`--count` 不足 8 时优先用前 N 个）：

1. 数字清单：`3 个 + 具体效果 + 人群`（例：3 步去黑头，油皮姐妹抄作业）
2. 痛点反问：`你是不是也 + 具体场景`（例：你是不是也这样，面膜越敷越干？）
3. 亲测揭秘：`我 + 试了 N 天/花了 N 钱 + 真实结果`（例：我连喝 7 天，这个豆浆粉真的绝）
4. 对比冲突：`A vs B + 出人意料`（例：99 块和 999 块的粉底，盲测结果惊了）
5. 紧急避坑：`N 个 + 坑/信号`（例：买防晒的 4 个坑，第 2 个最多人踩）
6. 身份代入：`人群 + 专属感`（例：熬夜党的救星，素颜也敢开视频了）
7. 悬念留白：`结果前置 + 原因后置`（例：空瓶第 3 罐，终于知道为啥火了）
8. 情绪共鸣：`说出心里话`（例：30 岁后才懂，贵的东西除了贵没毛病）

### 2. 四维打分

| 维度 | 权重 | 打分问题 |
|---|---|---|
| 痛点浓度 | 30 | 目标人群看到会"说的就是我"吗 |
| 信息明确 | 25 | 不看正文，能猜出这篇讲什么吗 |
| 点击冲动 | 25 | 有让人想点开的钩子（数字/悬念/冲突）吗 |
| 合规安全 | 20 | 有极限词/标题党/断言吗（有则本项 0 分） |

输出打分表，Top1 标出。**铁律**：标题 ≤ 20 字（含标点/emoji）；超了直接出局，不参与打分。

### 3. 交付

- Top1 标题 + 2 个备选（不同公式），注明每个的公式来源和打分。
- 提醒：标题党（承诺正文没兑现）会被判"文不对题"限流，`xhs-audit` 会复核兑现情况。

## 注意事项

- 标题里至少带一个具体元素：数字 / 人群 / 场景 / 价格，四者至少其一。
- emoji ≤ 3 个，放标题开头或结尾，不许插在句子中间断句。
- 同一产品 3 篇笔记以内不许重复用同一公式（防审美疲劳）。
