# /lhg-xiaohongshu:xhs —— 种草笔记一键生成

用户输入在 `$ARGUMENTS` 中：`<产品卖点/一句话> [--cover-only] [--no-cover]`。
`--cover-only` 只出封面图规范与绘制脚本；`--no-cover` 跳过封面环节。

全程按 3 个 skill 的顺序推进：`lhg-xhs-copy` → `lhg-xhs-cover` → `lhg-xhs-compliance`。

## 流程

### 1. 种草文案（lhg-xhs-copy）
- 先提炼卖点：从用户的一句话里拆出 3 个核心卖点（功能卖点 / 情感卖点 / 价格卖点），每个卖点 1 句话。
- 输出 3 版标题（每版用不同公式：数字清单 / 痛点反问 / 亲测揭秘），标题 ≤ 20 字。
- 写正文 1 版：痛点开场（100 字内）→ 亲测过程（细节+数字）→ 优缺点（缺点必须写 1 条，真实才可信）→ 购买建议。正文 300~800 字。
- 标签 5~8 个：2 个大流量词 + 3 个精准词 + 1~2 个品牌词，放在正文末尾。

### 2. 封面图（lhg-xhs-cover）
- 按封面 skill 出 1 张封面：尺寸 **1242×1660**（3:4），标题大字 ≤ 12 字，字号 ≥ 120px 对比强烈。
- 交付方式：输出一份"封面绘制说明"（文案/配色/构图/字号），并给出用 Canvas/SVG 确定性绘制的代码骨架（HTML+Canvas，纯手写，不依赖外部服务）。
- `--no-cover` 时跳过本步；`--cover-only` 时只做本步。

### 3. 合规检测（lhg-xhs-compliance + 脚本）
- 先跑确定性脚本（必做）：
```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/audit/xhs_audit.py --target notes/<本次笔记> --format text
```
- blocker（广告法极限词：最/第一/国家级；封面尺寸比例错误）必须清零。
- warning（标题过长、标签数不对、功效断言）逐条修。
- 再按合规 skill 做人工复核：营销号限流风险、"广告"标识、医疗/金融题材声明。

### 4. 发布草稿交付
- 输出发布草稿包：`notes/<日期>-<产品>.md`（标题 3 选 1 标记 + 正文 + 标签）+ `cover-1242x1660.png`（或绘制代码）。
- 打印合规报告摘要 + 发布时间建议（工作日晚 8~10 点 / 周末上午 10 点）+ 评论区运营话术（置顶评论 1 条、回复模板 3 条）。

## 注意事项

- 全程中文输出，语气按 lhg-xhs-copy 的"真人感"规范（说人话，不许"笔者体"）。
- 功效描述只讲"我的体验"，不许写"保证/根治/100% 有效"类断言。
- 发布动作（小红书 App / 网页发布）**永远由用户亲手做**；涉及账号登录的操作一律不代劳。
