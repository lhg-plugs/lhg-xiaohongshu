# lhg-xhs-cover：小红书封面图规范

> 目标：封面决定点击率。信息流里你的封面只有 0.5 秒机会——大字够不够大、主体清不清晰，一眼定生死。
> 核心纪律：**尺寸 1242×1660 是铁律，标题大字 ≤ 12 字，手机端缩略图可读才算合格。**

## 1. 何时使用

- 生成种草笔记需要封面时 → 按本 skill 出绘制说明 + 绘制代码
- 封面总没点击率 → 按第 6 节自查清单逐项排查
- 用户给了一张图要改成封面 → 按第 5 节裁剪规范处理

## 2. 尺寸铁律

| 项目 | 规范 | 说明 |
|---|---|---|
| 标准尺寸 | **1242 × 1660 px** | 3:4 竖版，小红书信息流展示比例 |
| 最低要求 | 比例 3:4（±2%） | 比例不对会被裁剪或留白，主体可能被切掉 |
| 分辨率 | ≥ 72dpi，文件 < 10MB | 太大传不上去，太小糊 |
| 安全区 | 上下各留 120px | 顶部标题栏、底部点赞栏会遮挡，别把字放边缘 |

**为什么是 1242×1660**：这是小红书官方推荐的封面尺寸（3:4）。用 1080×1080 方图，信息流里显示区域小一圈，点击率天然吃亏。

## 3. 构图：三分法 + 主体突出

封面 = 背景 + 主体 + 标题大字，三层：

1. **背景**：纯色 / 渐变 / 虚化实拍，**不许**花哨。背景的作用是衬托，不是抢戏。推荐：米白 #F5F1E8、雾蓝 #DCE9F5、浅粉 #F9E2E2。
2. **主体**：产品或人物，占画面 40%~60%，放在中下部（三分法下 1/3 处）。主体边缘要清晰，抠图毛边是大忌。
3. **标题大字**：放在上 1/3 处，≤ 12 字，字号 ≥ 120px，描边或底色块保证可读。

```
┌──────────────┐
│  标题大字     │  ← 上1/3，≤12字，≥120px
│  （描边/底色） │
├──────────────┤
│              │
│    主体      │  ← 中下部，占40%~60%
│   （产品）    │
│              │
└──────────────┘
   ↑ 上下各留120px安全区
```

## 4. 标题大字规范

- **字数**：≤ 12 字。12 字是上限，不是目标，8 字以内最好。
- **字号**：≥ 120px（按 1242 宽算）。检验方法：把图缩到手机信息流大小（宽约 300px），字还认得清才算过。
- **字体**：黑体/圆体，**不许**用细体、艺术体（小字号下糊成一团）。
- **颜色**：字色与背景对比度 ≥ 4.5:1。白底黑字最保险；彩色底用白字 + 深色描边。
- **内容**：直接用笔记标题的浓缩版，不许和标题完全无关。例：标题《3 步去黑头，油皮姐妹抄作业》→ 封面大字「3 步去黑头」。

## 5. 配图处理规范

- **实拍图**：优先用实拍（产品/上脸/场景），真实感 > 精美度。小红书用户对"广告级精修"有天然警惕。
- **裁剪**：从原图裁 3:4 时，主体居中，**不许**切掉产品关键部位（瓶身文字、人物眼睛）。
- **拼图**：最多 2 张（前后对比/细节特写），拼图接缝对齐，不许一高一低。
- **水印**：不许加个人水印遮挡主体（平台会降权）；品牌 logo 放角落，≤ 80px。
- **滤镜**：轻微提亮可以，重度滤镜（磨皮到失真）不许——会被质疑造假。

## 6. 封面自查清单（发布前逐项）

- [ ] 尺寸 = 1242×1660（脚本 XHS-COVER 规则会自动验）
- [ ] 缩到 300px 宽，标题大字认得清
- [ ] 主体完整，没被裁掉关键部位
- [ ] 上下 120px 安全区内无重要文字
- [ ] 字色/背景对比强烈，不费眼
- [ ] 无个人水印遮挡主体
- [ ] 标题大字 ≤ 12 字，与笔记标题呼应

## 7. Canvas 确定性绘制方法

AI 生图写不好中文大字（笔画错乱是常态），所以封面走"确定性绘制"路线：用 HTML Canvas 按规范精确绘制，**所见即所得**，零玄学。

绘制步骤：

1. 创建 1242×1660 画布，填充背景色（纯色/渐变二选一）。
2. 绘制主体占位区（中下部）：如果是产品图，用 `drawImage` 按比例放入；纯文字封面则跳过。
3. 绘制标题大字：上 1/3 处居中，黑体 ≥ 120px，白色字 + 深色描边（`strokeText` + `fillText`）。
4. 导出 PNG：`canvas.toDataURL('image/png')`，校验尺寸无误后交付。

**绘制代码骨架**（HTML 文件，浏览器打开即渲染，右键另存为 PNG）：

```html
<!DOCTYPE html>
<html><head><meta charset="utf-8"><title>封面</title></head>
<body style="margin:0">
<canvas id="c" width="1242" height="1660"></canvas>
<script>
const c = document.getElementById('c'), x = c.getContext('2d');
// 1. 背景
const g = x.createLinearGradient(0, 0, 0, 1660);
g.addColorStop(0, '#F5F1E8'); g.addColorStop(1, '#E8DCC8');
x.fillStyle = g; x.fillRect(0, 0, 1242, 1660);
// 2. 标题大字（上1/3，≤12字，≥120px）
x.font = 'bold 140px sans-serif';
x.textAlign = 'center';
x.lineWidth = 10; x.strokeStyle = '#333';
x.fillStyle = '#fff';
const title = '3 步去黑头';  // ← 改成你的封面文案
x.strokeText(title, 621, 420);
x.fillText(title, 621, 420);
// 3. 主体区占位（把产品图画在这里，或删掉做纯文字封面）
x.fillStyle = 'rgba(0,0,0,0.06)';
x.fillRect(171, 700, 900, 760);
x.fillStyle = '#999'; x.font = '48px sans-serif';
x.fillText('产品图放这里', 621, 1080);
// 4. 底部安全区提示（交付前删掉）
x.fillStyle = '#c00'; x.font = '36px sans-serif';
x.fillText('↓ 底部120px安全区，无重要内容', 621, 1600);
</script>
</body></html>
```

**使用说明**：把 `title` 换成你的封面文案（≤ 12 字），背景色换成你的配色，浏览器打开后右键"图片另存为"即得 1242×1660 PNG。主体有实拍图时，把占位矩形换成 `drawImage(产品图)`。

## 8. 反模式

- ❌ 方图/横图当封面——信息流显示小一圈，点击率天然低
- ❌ 标题大字 20 个字——缩略图下糊成一片，等于没写
- ❌ 细体艺术字——好看但看不清，封面首先是"看清"其次才是"好看"
- ❌ AI 生图直出当封面——中文大字大概率笔画错误，先检查再发布
- ❌ 主体被安全区裁掉——字压在点赞按钮下，用户看不到

## 9. 自检与反馈

做完封面自问：

1. 自查清单 7 项全过了吗？→ 有一项没过就不算完。
2. 缩略图测试做了吗（300px 宽看字）？→ 没做不算完。
3. 绘制代码在浏览器打开验证了吗？→ 尺寸不对就调，别凭感觉。

标准冒烟用例：用第 7 节代码骨架生成一张封面，跑 `xhs_audit.py` 确认 XHS-COVER-002 通过（尺寸 1242×1660）。

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-xiaohongshu/issues，正文写清"输入 → 错误输出 → 期望输出"。
