# lhg-xhs-copy：小红书种草文案方法论

> 目标：写出"像真人分享、不像广告"的种草笔记。种草的本质是信任，信任的本质是细节和真诚。
> 核心纪律：**每篇笔记必须有 1 个真实细节（时间/数字/场景），没有细节的种草就是硬广。**

## 1. 何时使用

- 用户给产品卖点，要生成种草笔记 → 全流程使用
- 只要标题 → 用第 3 节公式库（对应 `/xhs-title`）
- 笔记写完总觉得"广告味太重" → 看第 7 节"去广告味"清单

## 2. 卖点提炼（三句话法）

用户的一句话卖点太粗，先拆成三句话：

1. **功能卖点**：它解决了什么具体问题？（`去黑头：鼻贴撕拉 3 分钟，黑头浮出来一半`）
2. **情感卖点**：用了之后什么感觉？（`素颜开视频不心虚了`）
3. **价格卖点**：凭什么值得买？（`99 块用 3 个月，一天不到 1 块钱`）

**提炼纪律**：每句话必须带一个具体元素（数字/场景/对比）。"效果很好""性价比超高"这种话等于没说，直接删掉重写。

## 3. 标题公式库（8 大公式）

小红书标题 ≤ 20 字（含标点/emoji），超了在信息流里会被截断，等于白写。

1. **数字清单**：`N 个/步 + 具体效果 + 人群`——例《3 步去黑头，油皮姐妹抄作业》
2. **痛点反问**：`你是不是也 + 具体场景`——例《你是不是也这样，面膜越敷越干？》
3. **亲测揭秘**：`我 + 试了 N 天/花了 N 钱 + 真实结果`——例《连喝 7 天，这个豆浆粉真的绝》
4. **对比冲突**：`A vs B + 出人意料的结果`——例《99 块和 999 块粉底盲测，结果惊了》
5. **紧急避坑**：`N 个 + 坑/信号`——例《买防晒的 4 个坑，第 2 个最多人踩》
6. **身份代入**：`人群标签 + 专属感`——例《熬夜党的救星，素颜也敢开视频了》
7. **悬念留白**：`结果前置，原因后置`——例《空瓶第 3 罐，终于知道为啥火了》
8. **情绪共鸣**：`说出目标人群的心里话`——例《30 岁后才懂：贵的东西除了贵没毛病》

**标题纪律**：emoji ≤ 3 个，放开头或结尾；不许出现"最/第一/国家级"（极限词，发布自检会拦截）；标题承诺必须在正文前 100 字兑现。

## 4. 正文结构：痛点 → 亲测 → 优缺点 → 建议

全文 300~800 字，四段式（小红书用户没耐心看长文）：

**第一段：痛点开场（≤ 100 字）**
描述一个具体场景，让目标人群"对号入座"。用"你"开头。

```
你是不是也这样：鼻子上的黑头，挤了长、长了挤，
鼻贴撕到红肿，第二天照样冒出来？
```

**第二段：亲测过程（200~400 字）**
讲"我"是怎么用的，细节越多越可信。必须包含：用了多久、怎么用的、什么变化（带数字）。

```
我连用了 7 天，每天晚上洗完脸敷 3 分钟。
第 3 天，鼻头摸起来没那么多颗粒感了；
第 7 天，对着光看，黑头少了一半左右。
```

**第三段：优缺点（各 1~2 条，缺点必须写）**
只夸不贬 = 广告；有 1 条真诚的缺点，可信度翻倍。

```
优点：温和不刺激，我这种敏感肌没泛红。
缺点：味道有点像中药，介意味道的姐妹慎入。
```

**第四段：购买建议（≤ 100 字）**
给明确的行动建议，顺手放价格锚点。

```
油皮/混油姐妹闭眼入，干皮先买小包装试试。
99 块 100 片，能用 3 个月，学生党也负担得起。
```

## 5. 标签策略（5~8 个）

标签放在正文末尾，另起一行。配比：

- **2 个大流量词**：`#护肤 #种草`（蹭大流量，竞争也大）
- **3 个精准词**：`#去黑头 #油皮护肤 #鼻贴测评`（精准人群，转化高）
- **1~2 个品牌词/自创词**：`#XX 牌测评`（沉淀搜索）

**标签纪律**：3~10 个，少了没流量，多了像 spam；不许堆砌无关大词（卖鼻贴打 `#美食` 会被判营销号）。

## 6. 评论区运营（发布后 24 小时）

笔记发出去，工作只做了一半：

1. **置顶评论**：自己抢一楼，补充正文没写的信息。例：`补充一下：我是在官方旗舰店买的，99 块，链接在主页橱窗～`
2. **回复模板**（准备 3 条）：
   - 问价格：`我买的时候 99，具体以店铺实时价为准哦～`
   - 问肤质适不适合：`我是混油皮用的，你是什么肤质？我帮你看看`
   - 差评/质疑：`谢谢姐妹提醒！每个人肤质不同，建议先买小包装试试～`（不许吵架）
3. **回复时效**：发布后 2 小时内的评论必须回，这是平台给初始流量的关键窗口。

## 7. 去广告味清单（写完逐项检查）

- [ ] 全文"我"≥ 3 次，"你"≥ 2 次（没有人称的是说明书，不是种草）
- [ ] 至少 1 个真实细节（时间/数字/场景），没有就回去补
- [ ] 缺点写了 1 条真的缺点（"唯一的缺点是太好用了"不算缺点）
- [ ] 没有"最/第一/国家级/保证/100% 有效"（极限词自查脚本会抓）
- [ ] 功效表述全是"我的体验"口吻（"我用了感觉…"而不是"它能…"）
- [ ] 价格只陈述事实（"我买的时候 99"），不做"全网最低"承诺
- [ ] 朗读一遍：像跟闺蜜聊天吗？不像就重写

## 8. 不同类目的微调

方法论通用，但四个高频类目各有雷区，写之前先看：

| 类目 | 加分项 | 雷区 |
|---|---|---|
| 美妆护肤 | 上脸前后对比描述（"第 3 天泛红少了"）；写肤质（混油/干皮） | 不许写"美白/祛痘/根治"类功效断言；前后对比图不许 P 过度 |
| 食品饮料 | 口味细节（"咸甜口，嚼得到果粒"）；场景（办公室/追剧） | 不许写"减肥/降糖/治病"；保质期/配料表如实写 |
| 数码 3C | 参数讲人话（"5000mAh≈重度用一天"）；真实续航实测 | 不许编跑分；"吊打/秒杀"算极限词擦边，慎用 |
| 母婴 | 写宝宝月龄 + 使用场景；安全细节（材质/认证） | 绝对不许功效断言；奶粉/辅食类建议直接劝退式谨慎，不接都行 |

**通用原则**：离身体越近的类目（吃进嘴、抹上脸、给孩子用），措辞越要保守。流量诚可贵，账号价更高。

## 9. 反模式

- ❌ 开头就是产品介绍——小红书不是说明书，没人关心"这款产品采用了 XX 技术"
- ❌ 全文夸、无缺点——读者又不傻，完美的测评=广告
- ❌ 功效断言（"7 天根治痘痘"）——违规 + 被打假博主挂，两种死法
- ❌ 标签堆 20 个——平台判 spam，限流
- ❌ 评论区不回复——初始流量窗口浪费了，等于白发
- ❌ 一篇爆了就连发 5 篇同款硬广——营销号判定，限流 7 天起

## 10. 自检与反馈

写完笔记自问：

1. 去广告味清单 7 项全过了吗？→ 有一项没过就不算完。
2. 标题 ≤ 20 字且 8 公式能对上号吗？→ 对不上说明标题是拍脑袋的，重写。
3. 评论区 3 条回复模板准备好了吗？→ 没准备就别点发布。

标准冒烟用例：输入"一款 99 块的去黑头鼻贴"跑一遍，检查输出是否含 3 版标题、正文四段、5~8 个标签、置顶评论话术。

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-xiaohongshu/issues，正文写清"输入 → 错误输出 → 期望输出"。
